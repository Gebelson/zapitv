# Arquitetura alvo

Preservar facades publicas. Contratos de dominio independentes de React. Configuracao administrativa server-side; transporte, descoberta e decisao de reproducao separados. Uma superficie de video. Extrair responsabilidades comprovadas, nao mover arquivos por estetica.

Gate P0: sem desmembramento de registry, verification ou ZapiPlayer antes da validacao descoberta -> selecao -> frame e regressao temporal. Ferramentas e contratos independentes podem prosseguir.
